# C-Cut — tải bộ cài

App dựng video **talking head** bất động sản, chạy hoàn toàn trên máy bạn.

👉 **Tải bản mới nhất:** [Releases](../../releases/latest)

| Máy | File |
|---|---|
| Mac chip M (M1/M2/M3/M4…) | `C-Cut-mac-arm64.dmg` |
| Mac chip Intel | `C-Cut-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `C-Cut-Setup.exe` |

Cần có trước: **Claude Code** (đăng nhập tài khoản Claude). Windows cần thêm **Git for Windows**.
Xem chi tiết trong file *Hướng dẫn sử dụng* đi kèm mỗi bản.

> Mac: lần đầu mở, chuột phải vào C-Cut → **Mở**. Windows: nếu hiện SmartScreen, bấm **More info → Run anyway**.
